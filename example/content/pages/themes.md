# Themes

Thirty official themes ship inside the binary, every one on the same token API and theme contract, so swapping is one config line and your overrides never fork. Each card links to the [live exhibition](https://cherrybomb.dev/t/), where every theme wears the same site, and to that theme's guide on customising it the Cherry way.
